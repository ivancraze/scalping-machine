# Контекст проекта для продолжения работы с ИИ

Этот файл нужен, чтобы открыть проект на другом компьютере или в новом чате и быстро дать ИИ корректный контекст.

## Коротко

**Pulse Terminal** — личный крипто-скринер для наблюдения за рынком. Он не торгует, не выставляет ордера и не должен хранить торговые ключи в браузере.

Текущий стек: Vite, React, TypeScript, SCSS Modules, TanStack Query, Axios, Lightweight Charts и набор `difurious/lightweight-charts-line-tools-*`.

Текущий источник данных — публичный **Binance USD-M Futures REST API** без API-ключей. Все запросы идут через TanStack Query и единый Axios-клиент. Список включает действующие бессрочные USDT-контракты; справочник инструментов кэшируется на 5 минут с объединением одновременных запросов.

## Как начать на новом компьютере

1. Склонировать или скопировать весь проект вместе с `package.json`, `package-lock.json` и markdown-документацией.
2. Установить Node.js 20+.
3. В папке проекта выполнить:

   ```powershell
   npm install
   npm run dev
   ```

4. Перед первой правкой нового агента попросить его прочитать в таком порядке:

   1. `AGENTS.md`;
   2. этот файл (`PROJECT_CONTEXT.md`);
   3. `PROJECT_GOALS.md`;
   4. `TODO.md`;
   5. `README.md`.

5. После кодовых изменений запускать:

   ```powershell
   npm run check
   ```

## Текущее состояние интерфейса

- брендовый блок `PULSE` и единственная вкладка «Список наблюдения»;
- большой свечной график слева и список монет справа;
- поиск и сортировка списка по названию, объёму, изменению цены, NATR и корреляции с BTC;
- переключатели таймфреймов в строке состояния графика;
- объём в нижней части графика;
- левая панель быстрых объектов: горизонтальный уровень, трендовая линия, горизонтальный луч, прямоугольник;
- раскрытое меню остальных инструментов line-tools;
- правый клик удаляет выбранный объект;
- SCSS Modules находятся рядом со страницей и виджетом графика.

## Особенности и известные ограничения

### Данные

- Рынок обновляется REST-поллингом раз в 30 секунд.
- В списке доступны все действующие бессрочные USDT-контракты без порога оборота и ограничения 30 строк. Поиск и сортировка сбрасывают прокрутку; обновление рынка её сохраняет. Есть счётчик результатов и сообщение о пустом поиске.
- Ограничение 30 монет сохранено только для расчёта корреляции в текущей поисковой выборке; UI поясняет ограничение, непосчитанные значения показывает как «—» и размещает в конце сортировки по корреляции. Расчёт для всего рынка — отдельная задача.
- Свечи загружаются страницами по 1000 баров. График держит окно до 10 страниц и автоматически подгружает данные в обе стороны, позволяя дойти до начала торгов контракта. Начальный интервал — 1м.
- Ось и перекрестие показывают локальное время браузера; исходные Unix timestamps остаются UTC.
- Кнопки 1с, 5с и 15с отключены: реальная поддержка потребует trade stream, агрегации и хранилища.
- Корреляция с BTC вычисляется в браузере для 30 монет; TanStack Query кэширует и отменяет запросы, параллелизм ограничен пятью.

### График

- Объекты создаются нативным `line-tools` и привязаны к времени/цене.
- Пока они не сохраняются между перезагрузками. Это задача №1 из `TODO.md`.
- Пока подключены все пакеты инструментов сразу, поэтому production bundle примерно 622 kB minified. В будущем нужен dynamic import.
- Исторические страницы применяются через `setData()` с сохранением пользовательского масштаба; live-свечи поступают через единый Binance Futures WebSocket, обновляют TanStack Query-кэш и применяются через `series.update()`. Транспорт не находится в UI-компонентах.
- Меню дополнительных инструментов располагается у левой панели. Пока оно открыто, canvas отключает pointer events, чтобы график не перехватывал выбор в меню.

### Архитектура

FSD-миграция начата, но не закончена.

```text
src/
  app/App.tsx
  pages/market-terminal/ui/MarketTerminalPage.tsx
  widgets/chart/ui/Chart.tsx
  widgets/chart/ui/ChartCanvas.tsx
  entities/market/api/binance.ts
  entities/market/model/types.ts
  shared/
```

`Chart` владеет загрузкой свечей, таймфреймом, шапкой и панелью рисования. `ChartCanvas` управляет Lightweight Charts, сериями и line-tools. Страница подключает только `Chart` через публичный `widgets/chart/index.ts`. Деления ценовой шкалы допускают шаг в 100 раз меньше биржевого тика для сильного увеличения; исходные OHLC не меняются.

Следующие кандидаты на вынос из страницы: market list, сортировки, поиск и выбор символа.

## Что нельзя сломать

- Не превращать объекты графика в отдельный SVG-overlay: они должны оставаться line-tools.
- Не добавлять торговлю или хранение трейдинговых ключей.
- Не смешивать Spot и Futures без явного разделения.
- Не выносить секреты Telegram или бирж во фронтенд.
- Не копировать код, брендинг или ассеты чужих скринеров.
- Не удалять или переписывать чужие изменения без явного запроса.

## Как вести контекст дальше

- что появилось для пользователя;
- где лежит реализация;
- какие источники данных используются;
- известные ограничения, решения и принятые компромиссы;
