# Контекст проекта для продолжения работы с ИИ

Этот файл нужен, чтобы открыть проект на другом компьютере или в новом чате и быстро дать ИИ корректный контекст.

## Коротко

**Pulse Terminal** — личный крипто-скринер для наблюдения за рынком. Он не торгует, не выставляет ордера и не должен хранить торговые ключи в браузере.

Текущий стек: Vite, React, TypeScript, Ant Design 6.6.2, @ant-design/icons 6.3.4, SCSS Modules, TanStack Query, Axios, Lightweight Charts и набор `difurious/lightweight-charts-line-tools-*`.

Текущий источник данных — публичный **Binance USD-M Futures REST API** без API-ключей. Все запросы идут через TanStack Query и единый Axios-клиент. Список включает действующие бессрочные USDT-контракты; справочник инструментов кэшируется на 5 минут с объединением одновременных запросов.

## Как начать на новом компьютере

1. Склонировать или скопировать весь проект вместе с `package.json`, `package-lock.json` и markdown-документацией.
2. Установить Node.js 20+.
3. В папке проекта выполнить:

   ```powershell
   npm install
   npm run dev
   ```

4. Перед первой правкой нового агента попросить его прочитать в таком порядке:

   1. `AGENTS.md`;
   2. этот файл (`PROJECT_CONTEXT.md`);
   3. `PROJECT_GOALS.md`;
   4. `TODO.md`;
   5. `README.md`.

5. После кодовых изменений запускать:

   ```powershell
   npm run check
   ```

## Текущее состояние интерфейса

Экран переведён на Ant Design с русской локализацией и компактной темой. По умолчанию тема тёмная; переключатель в шапке включает светлую. Выбор сохраняется в `localStorage` (`pulse-terminal:theme`). Конфигурация темы и контекст находятся в `shared/theme`, провайдер — в `app/ThemeProvider.tsx`, переключатель — в `features/theme-switch`. SCSS Modules отвечают за компоновку и используют семантические CSS-переменные провайдера.

Список монет в `widgets/market-list` использует виртуальный Ant Design Table без пагинации и существующие функции поиска/сортировки. При обновлениях рынка и смене темы прокрутка сохраняется. Кнопки без реализованных функций отображаются отключёнными.

`ChartCanvas` принимает типизированную палитру и обновляет её отдельным эффектом `applyOptions()`. Тема не участвует в создании графика или применении свечных данных. Объём и открытый интерес размещены в нативных panes Lightweight Charts и включаются без пересоздания основного графика. Подтверждение удаления объектов реализовано через Ant Design Modal в `features/reset-chart-objects`; его экземпляр привязан к текущей паре и таймфрейму. Запрос сброса обрабатывается один раз, поэтому переход к другой паре не удаляет её сохранённые рисунки.

- брендовый блок `PULSE` и единственная вкладка «Список наблюдения»;
- большой свечной график слева и список монет справа;
- поиск и сортировка списка по названию, объёму, изменению цены, NATR и корреляции с BTC;
- переключатели таймфреймов и кнопка «Индикаторы» в шапке графика;
- отдельные изменяемые по высоте панели открытого интереса и объёма под свечами;
- левая панель быстрых объектов: горизонтальный уровень, трендовая линия, горизонтальный луч, прямоугольник, линейка изменения цены;
- раскрытое меню остальных инструментов line-tools;
- правый клик удаляет выбранный объект;
- SCSS Modules находятся рядом со страницей и виджетом графика.

## Особенности и известные ограничения

### Данные

- Рынок обновляется REST-поллингом раз в 30 секунд.
- В списке доступны все действующие бессрочные USDT-контракты без порога оборота и ограничения 30 строк. Поиск и сортировка сбрасывают прокрутку; обновление рынка её сохраняет. Есть счётчик результатов и сообщение о пустом поиске.
- Корреляция рассчитывается для пар с оборотом от $50M за 24 часа; UI поясняет порог, непосчитанные значения показывает как «—» и размещает в конце сортировки по корреляции.
- Свечи загружаются страницами по 1000 баров. График держит окно до 10 страниц и автоматически подгружает данные в обе стороны, позволяя дойти до начала торгов контракта. Начальный интервал — 1м.
- Ось и перекрестие показывают локальное время браузера; исходные Unix timestamps остаются UTC.
- Свечи 1с, 5с и 15с агрегируются из последних aggTrade и live-потока. Полноценная секундная история потребует отдельного хранилища.
- Корреляция с BTC вычисляется в браузере; TanStack Query кэширует и отменяет запросы, параллелизм ограничен.
- История открытого интереса Binance USD-M загружается лениво страницами по 500 значений и доступна только за последний месяц. Минимальный период источника — 5м, поэтому на 1с/5с/15с/1м панель обозначена как `OI · 5м`.

### График

- Объекты создаются нативным `line-tools` и привязаны к времени/цене.
- Линейка создаётся перетаскиванием или двумя кликами, имеет два редактируемых угла, осевые стрелки, диагональ и подпись с изменением цены, процентом и длительностью; цвет автоматически меняется между зелёным и красным по направлению.
- Рисунки сохраняются между перезагрузками в `localStorage`, раздельно по бирже, паре и таймфрейму.
- Все пакеты инструментов пока подключены сразу. После добавления панелей индикаторов JS составляет 1 493,89 kB (461,52 kB gzip), CSS — 7,98 kB (2,22 kB gzip); worker автоуровней — 9,41 kB. Предупреждение Vite о большом чанке сохраняется; dynamic import инструментов — отдельная задача.
- Исторические страницы применяются через `setData()` с сохранением пользовательского масштаба; live-свечи поступают через единый Binance Futures WebSocket, обновляют TanStack Query-кэш и применяются через `series.update()`. Транспорт не находится в UI-компонентах.
- Видимость, цвета и высоты панелей OI/объёма хранятся глобально в браузере как serializable preset-ready модель. Индикаторные series добавляются и удаляются независимо от candle series и line-tools.
- Меню дополнительных инструментов располагается у левой панели. Пока оно открыто, canvas отключает pointer events, чтобы график не перехватывал выбор в меню.

### Архитектура

FSD-миграция начата, но не закончена.

```text
src/
  app/App.tsx
  pages/market-terminal/ui/MarketTerminalPage.tsx
  widgets/chart/ui/Chart.tsx
  widgets/chart/ui/ChartCanvas.tsx
  features/chart-indicators/
  entities/market/api/binance.ts
  entities/market/model/types.ts
  shared/
```

`Chart` владеет загрузкой свечей, таймфреймом, шапкой и панелью рисования. `ChartCanvas` управляет Lightweight Charts, сериями и line-tools. Страница подключает только `Chart` через публичный `widgets/chart/index.ts`. Деления ценовой шкалы допускают шаг в 100 раз меньше биржевого тика для сильного увеличения; исходные OHLC не меняются.

Список монет уже вынесен в `widgets/market-list`; поиск и сортировки пока находятся внутри виджета. Переключение темы, подтверждение сброса объектов и настройки индикаторов находятся в `features`.

Текущие проверки: 132 теста, ESLint, Stylelint, форматирование исходников и production-сборка проходят. Полный `npm run check` останавливается на ранее существовавшем форматировании корневого `AGENTS.md`. В браузере проверены обе темы, сохранение выбора после перезагрузки, сортировка, поиск, выбор пары, меню инструментов, индикаторные панели и сохранение рисунков/диапазона при смене темы.

## Что нельзя сломать

- Не превращать объекты графика в отдельный SVG-overlay: они должны оставаться line-tools.
- Не добавлять торговлю или хранение трейдинговых ключей.
- Не смешивать Spot и Futures без явного разделения.
- Не выносить секреты Telegram или бирж во фронтенд.
- Не копировать код, брендинг или ассеты чужих скринеров.
- Не удалять или переписывать чужие изменения без явного запроса.

## Как вести контекст дальше

После каждой крупной завершённой функции обновлять этот файл:

- что появилось для пользователя;
- где лежит реализация;
- какие источники данных используются;
- известные ограничения, решения и принятые компромиссы;
- что обязательно проверить следующему агенту.

Так новый чат получает актуальную карту проекта, а не вынужден угадывать историю по коду.
