# Pulse Terminal

Клиентский крипто-терминал для наблюдения за рынком. Проект не выставляет ордера, не хранит ключи пользователя и не выполняет торговые операции.

Текущий MVP показывает действующие бессрочные USDT-фьючерсы Binance USD-M, позволяет искать и сортировать монеты, открывать свечной график и использовать нативные инструменты рисования на базе Lightweight Charts. Публичные рыночные данные доступны без API-ключей.

## Запуск

Требуется Node.js 20+ и npm.

```powershell
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Полная проверка проекта:

```powershell
npm run check
```

Она последовательно запускает ESLint, Stylelint, Prettier и production-сборку.

## Технологии

- Vite — dev-сервер и production-сборка;
- React + TypeScript — интерфейс и типизация;
- TanStack Query — кэш, отмена, polling и пагинация серверных данных;
- Axios — единый HTTP-клиент для Binance API;
- SCSS Modules — изолированные стили компонентов;
- `lightweight-charts` 5 — свечной график и объём;
- `lightweight-charts-line-tools-*` — нативные объекты, привязанные к времени и цене графика;
- публичное REST API Binance — рынок, свечи и стакан;
- ESLint + TypeScript ESLint + React Hooks — качество TypeScript/React-кода;
- Prettier — единый формат;
- Stylelint — проверка SCSS.

## Что реализовано

### Рынок

- загрузка всех бессрочных USDT-фьючерсов Binance со статусом TRADING, котировкой и обеспечением в USDT, без порога оборота; справочник контрактов кэшируется на 5 минут;
- полный список доступен прокруткой; счётчик показывает число результатов поиска и общее число загруженных контрактов;
- поиск и сортировка возвращают прокрутку в начало, обновление рынка сохраняет её позицию и выбранную монету;
- обновление списка раз в 30 секунд;
- поиск по тикеру;
- сортировка по названию, объёму за 24ч, изменению цены, волатильности (NATR) и корреляции с BTC;
- расчёт корреляции пока ограничен первыми 30 монетами текущей поисковой выборки в порядке API; отсутствующие значения отмечены «—» и находятся в конце при сортировке по корреляции;
- выбор строки открывает график соответствующей пары.

### График

- свечи и объём;
- начальная загрузка 1000 свечей и автоматическая подгрузка истории в обе стороны при прокрутке;
- окно до 10 000 свечей в памяти с возможностью дойти до первой доступной свечи контракта;
- последние свечи обновляются через Binance Futures WebSocket без перезагрузки исторических страниц;
- подписи оси времени и перекрестия в локальном часовом поясе браузера;
- таймфреймы в интерфейсе: 1с, 5с, 15с, 1м, 5м, 15м, 1ч, 4ч, 1д;
- доступны интервалы 1м и выше; кнопки 1с/5с/15с отключены до реализации агрегации сделок;
- горизонтальный уровень, трендовая линия, горизонтальный луч и прямоугольник доступны быстрыми кнопками;
- через меню доступны остальные подключённые line-tools: линии, кисти, фигуры, Фибо, ценовой диапазон, Long/Short, текст и т.д.;
- объекты принадлежат графику: корректно движутся при скролле, зуме и смене масштаба;
- правый клик удаляет выбранный объект.

## Архитектура

Структура мигрируется на Feature-Sliced Design.

```text
src/
  app/                         # точка композиции приложения
  pages/market-terminal/       # сценарий экрана терминала
  widgets/chart/               # Chart — интерфейс; ChartCanvas — Lightweight Charts
  entities/market/             # модели рынка и Binance-маппинг
  shared/                      # общие утилиты и инфраструктура
```

Стили лежат у владельцев интерфейса:

- `pages/market-terminal/ui/MarketTerminalPage.module.scss`;
- `widgets/chart/ui/Chart.module.scss`;
- `widgets/chart/ui/ChartCanvas.module.scss`;
- `styles.scss` содержит только глобальный reset и базовые токены страницы.

## Текущие ограничения и технический долг

- API-слой использует **Binance USD-M Futures** для списка, свечей и REST-стакана; Spot и COIN-M не подключены.
- Корреляция к BTC рассчитывается в браузере для 30 монет; запросы кэшируются, отменяются вместе с query и выполняются с параллелизмом не более пяти.
- Все пакеты line-tools подключаются в стартовый bundle. Production-бандл около 622 kB minified; инструменты следует загружать динамически по первому использованию.
- Исторические страницы применяются через `setData()` с сохранением видимого диапазона; live-свечи применяются инкрементально через `series.update()`.
- `MarketDepth` зарегистрирован как инструмент, но пока не получает live-данные стакана, поэтому не должен считаться готовым терминалом плотностей.
- FSD-миграция начата, но ещё не завершена: market list, сортировки, поиск и выбор инструмента пока находятся в странице, а не в `widgets`/`features`.
- Состояние нарисованных объектов не сохраняется между перезагрузками.

Pulse Terminal — инструмент наблюдения, списков и будущих сигналов. Торговая интеграция не входит в текущую область проекта.
