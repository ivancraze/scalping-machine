# Pulse Terminal

Клиентский крипто-терминал для наблюдения за рынком. Проект не выставляет ордера, не хранит ключи пользователя и не выполняет торговые операции.

Текущий MVP показывает список USDT-пар Binance, позволяет искать и сортировать монеты, открывать свечной график и использовать нативные инструменты рисования на базе Lightweight Charts.

## Запуск

Требуется Node.js 20+ и npm.

```powershell
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Полная проверка проекта:

```powershell
npm run check
```

Она последовательно запускает ESLint, Stylelint, Prettier и production-сборку.

## Технологии

- Vite — dev-сервер и production-сборка;
- React + TypeScript — интерфейс и типизация;
- SCSS Modules — изолированные стили компонентов;
- `lightweight-charts` 5 — свечной график и объём;
- `lightweight-charts-line-tools-*` — нативные объекты, привязанные к времени и цене графика;
- публичное REST API Binance — рынок, свечи и стакан;
- ESLint + TypeScript ESLint + React Hooks — качество TypeScript/React-кода;
- Prettier — единый формат;
- Stylelint — проверка SCSS.

## Что реализовано

### Рынок

- загрузка ликвидных USDT-пар Binance;
- обновление списка раз в 30 секунд;
- поиск по тикеру;
- сортировка по названию, объёму за 24ч, изменению цены, волатильности (NATR) и корреляции с BTC;
- выбор строки открывает график соответствующей пары.

### График

- свечи и объём;
- таймфреймы в интерфейсе: 1с, 5с, 15с, 1м, 5м, 15м, 1ч, 4ч, 1д;
- Binance REST в текущем MVP действительно отдаёт 1м и выше: 1с/5с/15с пока отображаются как 1м;
- горизонтальный уровень, трендовая линия, горизонтальный луч и прямоугольник доступны быстрыми кнопками;
- через меню доступны остальные подключённые line-tools: линии, кисти, фигуры, Фибо, ценовой диапазон, Long/Short, текст и т.д.;
- объекты принадлежат графику: корректно движутся при скролле, зуме и смене масштаба;
- правый клик удаляет выбранный объект.

## Архитектура

Структура мигрируется на Feature-Sliced Design.

```text
src/
  app/                         # точка композиции приложения
  pages/market-terminal/       # сценарий экрана терминала
  widgets/chart-workspace/     # виджет графика и его SCSS module
  entities/market/             # модели рынка и Binance-маппинг
  shared/                      # общие утилиты и инфраструктура
```

Стили лежат у владельцев интерфейса:

- `pages/market-terminal/ui/MarketTerminalPage.module.scss`;
- `widgets/chart-workspace/ui/ChartCanvas.module.scss`;
- `styles.scss` содержит только глобальный reset и базовые токены страницы.

## Текущие ограничения и технический долг

- API-слой сейчас использует **Binance Spot**, хотя в UI написано «Binance Futures». Перед подключением фьючерсных данных требуется отдельный exchange-adapter.
- Корреляция к BTC получает историю для ряда монет прямо в браузере. Нужны кэширование, отмена запросов и ограничение параллельности.
- Все пакеты line-tools подключаются в стартовый bundle. Production-бандл около 530 kB minified; инструменты следует загружать динамически по первому использованию.
- При каждом обновлении свечей график выполняет `setData()` и `fitContent()`. Для WebSocket-режима нужны инкрементальные `series.update()` и сохранение пользовательского масштаба.
- `MarketDepth` зарегистрирован как инструмент, но пока не получает live-данные стакана, поэтому не должен считаться готовым терминалом плотностей.
- FSD-миграция начата, но ещё не завершена: market list, сортировки, поиск и выбор инструмента пока находятся в странице, а не в `widgets`/`features`.
- Состояние нарисованных объектов не сохраняется между перезагрузками.
