# Pulse Terminal

Клиентский крипто-терминал для наблюдения за рынком. Проект не выставляет ордера, не хранит ключи пользователя и не выполняет торговые операции.

Текущий MVP показывает действующие бессрочные USDT-фьючерсы Binance USD-M, позволяет искать и сортировать монеты, наблюдать за ними в отдельной сетке живых графиков, открывать большой свечной график, использовать нативные инструменты рисования и автоматически находить уровни поддержки, сопротивления и тренда. Публичные рыночные данные доступны без API-ключей.

## Запуск

Требуется Node.js 20+ и npm.

```powershell
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Полная проверка проекта:

```powershell
npm run check
```

Она последовательно запускает ESLint, Stylelint, Prettier, Vitest и production-сборку.

## Технологии

- Vite — dev-сервер и production-сборка;
- React + TypeScript — интерфейс и типизация;
- Ant Design 6.6.2 и @ant-design/icons 6.3.4 — компоненты интерфейса, русская локализация и темы;
- TanStack Query — кэш, отмена, polling и пагинация серверных данных;
- Axios — единый HTTP-клиент для Binance API;
- SCSS Modules — изолированные стили компонентов;
- `lightweight-charts` 5 — свечной график и отдельные панели индикаторов;
- `lightweight-charts-line-tools-*` — нативные объекты, привязанные к времени и цене графика;
- публичное REST API Binance — рынок, свечи, открытый интерес и стакан;
- ESLint + TypeScript ESLint + React Hooks — качество TypeScript/React-кода;
- Prettier — единый формат;
- Stylelint — проверка SCSS.

## Интерфейс и темы

Весь текущий экран использует компактные компоненты Ant Design: навигацию, поиск, виртуальную таблицу монет, таймфреймы, кнопки, меню рисования, подсказки и подтверждение удаления объектов. График сохраняет движок Lightweight Charts и нативные line-tools.

Переключатель в правой части шапки меняет светлую и тёмную темы. При первом открытии используется тёмная тема; ручной выбор сохраняется в `localStorage` под ключом `pulse-terminal:theme`. Если хранилище недоступно, переключение работает до закрытия страницы. Палитра графика обновляется через `applyOptions()`, без пересоздания графика, сброса масштаба или изменения цветов сохранённых рисунков.

Конфигурация и хранение темы находятся в `shared/theme`, провайдер — в `app/ThemeProvider.tsx`, переключатель — в `features/theme-switch`. Подтверждение сброса — в `features/reset-chart-objects`; оно закрывается при смене пары или таймфрейма. Настройки индикаторов и выбранные пользователем высоты панелей общие для всех графиков и сохраняются в `localStorage`.

## Что реализовано

### Рынок

- загрузка всех бессрочных USDT-фьючерсов Binance со статусом TRADING, котировкой и обеспечением в USDT, без порога оборота; справочник контрактов кэшируется на 5 минут;
- полный список доступен прокруткой; счётчик показывает число результатов поиска и общее число загруженных контрактов;
- поиск и сортировка возвращают прокрутку в начало, обновление рынка сохраняет её позицию и выбранную монету;
- обновление списка через Binance Futures WebSocket с REST-поллингом раз в 30 секунд;
- поиск по тикеру;
- сортировка по названию, объёму за 24ч, изменению цены, волатильности (NATR) и корреляции с BTC;
- корреляция рассчитывается для пар с оборотом от $50M за 24 часа; отсутствующие значения отмечены «—» и находятся в конце при сортировке по корреляции;
- таблица использует виртуализацию без пагинации; поиск и смена сортировки сбрасывают прокрутку, обновления данных и смена темы сохраняют её;
- выбор строки открывает график соответствующей пары.

### График

- свечи, объём и стоимость открытого интереса Binance USD-M в независимых изменяемых по высоте панелях;
- кнопка «Индикаторы» включает и выключает объём/OI, настраивает их цвета и восстанавливает значения по умолчанию без пересоздания основного графика;
- история OI загружается страницами по 500 точек до доступного Binance предела в 30 дней; на 1с/5с/15с/1м честно используется минимальный период источника 5м;
- начальная загрузка 1000 свечей и автоматическая подгрузка истории в обе стороны при прокрутке;
- окно до 10 000 свечей в памяти с возможностью дойти до первой доступной свечи контракта;
- последние свечи обновляются через Binance Futures WebSocket без перезагрузки исторических страниц;
- подписи оси времени и перекрестия в локальном часовом поясе браузера;
- таймфреймы в интерфейсе: 1с, 5с, 15с, 1м, 5м, 15м, 1ч, 4ч, 1д;
- секундные свечи агрегируются из последних Binance Futures aggTrade и live-потока; полноценная секундная история требует отдельного хранилища;
- горизонтальный уровень, трендовая линия, горизонтальный луч и прямоугольник доступны быстрыми кнопками;
- линейка измеряет изменение между двумя редактируемыми точками: показывает цену, процент и время, меняет цвет по направлению и рисует осевые стрелки с диагональю;
- через меню доступны остальные подключённые line-tools: линии, кисти, фигуры, Фибо, ценовой диапазон, Long/Short, текст и т.д.;
- автоуровни по закрытым свечам рассчитываются в Web Worker на основном таймфрейме графика и рисуются нативными лучами от первого экстремума; на секундных графиках анализ честно остаётся минутным из-за ограниченной секундной истории; пробойный детектор ищет повторные касания рядом с ценой, а отдельный режим `EX` — одиночные и подтверждённые swing-экстремумы с зоной по волатильности;
- автоматические линии можно отключать, удалять и замораживать; они визуально отделены от ручной разметки и не попадают в её сохранённый layout;
- объекты принадлежат графику: корректно движутся при скролле, зуме и смене масштаба;
- правый клик удаляет выбранный объект;
- рисунки сохраняются в браузере раздельно по бирже, паре и таймфрейму; сброс с подтверждением удаляет только разметку текущего графика.

### Сетка графиков

- отдельные маршруты `/watchlist` и `/grid` переключаются верхними вкладками «Список наблюдения» и «Сетка»;
- представления: все монеты, закладки, лидеры роста, лидеры падения и активные по числу сделок;
- поиск и базовые фильтры по объёму, сделкам и изменению цены; порядок live-рынка фиксируется на четыре секунды,
  чтобы карточки не прыгали при каждом обновлении;
- именованные пресеты сохраняют условия по обороту, изменению, диапазону, сделкам и NATR 5м/14, сортировку,
  лимит, стартовый таймфрейм и чёрный список; перед сохранением показываются число и первые подходящие тикеры;
- 2 / 3 / 4 колонки, прокручиваемый и постраничный режимы по два ряда;
- общий таймфрейм `1м / 3м / 5м / 15м / 30м / 1ч / 4ч / 1д` переключает все карточки; у каждой карточки
  остаётся независимое переопределение;
- свечи, объём и OI в нативных panes Lightweight Charts; для 1м честно используется история `OI · 5м`;
- видимые карточки показывают funding Binance и время следующего начисления; технические данные имеют краткий
  и подробный режим, подписи шкал отключаются общим переключателем;
- шаг цены адаптируется к стоимости инструмента и остаётся компактным на правой шкале;
- настройки сетки и локальные таймфреймы сохраняются в versioned `localStorage`;
- scroll-режим виртуализирует строки с overscan, pages-режим монтирует только текущую страницу; REST-история
  свечей/OI ограничена общим пулом из пяти запросов;
- карточку можно развернуть, открыть на весь экран или передать её символ и таймфрейм в большой график.

Для корректного обновления вложенных маршрутов на Vercel в `vercel.json` настроен SPA rewrite на `index.html`.

## Архитектура

Структура мигрируется на Feature-Sliced Design.

```text
src/
  app/                         # точка композиции приложения
  pages/market-grid/           # отдельная страница сетки наблюдения
  pages/market-terminal/       # сценарий экрана терминала
  widgets/chart/               # Chart — интерфейс; ChartCanvas — Lightweight Charts
  features/auto-levels/        # настройки, lifecycle worker и заморозка уровней
  features/chart-indicators/   # UI и локальные preset-ready настройки индикаторов
  features/market-grid-controls/ # настройки, фильтры и storage сетки
  entities/auto-level/         # модель и детерминированный детектор уровней
  entities/market/             # модели рынка и Binance-маппинг
  shared/                      # общие утилиты и инфраструктура
```

Стили лежат у владельцев интерфейса:

- `pages/market-terminal/ui/MarketTerminalPage.module.scss`;
- `widgets/chart/ui/Chart.module.scss`;
- `widgets/chart/ui/ChartCanvas.module.scss`;
- `styles.scss` содержит только глобальный reset и базовые токены страницы.

## Текущие ограничения и технический долг

- API-слой использует **Binance USD-M Futures** для списка, свечей и REST-стакана; Spot и COIN-M не подключены.
- Binance предоставляет историю OI только за последний месяц и с минимальным периодом 5 минут; более младшие графики явно показывают `OI · 5м`.
- Корреляция к BTC рассчитывается в браузере для пар с оборотом от $50M; запросы кэшируются, отменяются вместе с query и выполняются с ограниченным параллелизмом.
- Страницы терминала и сетки загружаются отдельными чанками; сетка использует отдельный public entry компактного
  графика и не импортирует UI большого графика. Тяжёлые line-tools большого графика всё ещё требуют дальнейшей
  декомпозиции. Vite предупреждает о чанке market-data/Ant Design больше 500 kB.
- Исторические страницы применяются через `setData()` с сохранением видимого диапазона; live-свечи применяются инкрементально через `series.update()`.
- `MarketDepth` зарегистрирован как инструмент, но пока не получает live-данные стакана, поэтому не должен считаться готовым терминалом плотностей.
- FSD-миграция начата, но ещё не завершена: список монет находится в `widgets/market-list`, поиск и сортировки пока остаются внутри виджета.
- Рисунки и тема хранятся локально в браузере, синхронизации между устройствами нет.
