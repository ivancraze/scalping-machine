# React-фичи Pulse Terminal

Перед работой прочитай корневой `AGENTS.md` и связанные файлы владельца изменяемого поведения. Учитывай `README.md` или `TODO.md`, только если задача затрагивает описанное там текущее состояние или план.

## Реализация

1. Определи владельца поведения по FSD и используй существующий public API слоя. Новые крупные блоки размещай в `widgets`, пользовательские действия — в `features`, рыночные модели и преобразования — в `entities`, инфраструктуру — в `shared`.
2. Оставляй серверное состояние, кэширование и отмену запросов в TanStack Query. Локальное состояние интерфейса держи рядом с его владельцем и не переноси в query cache без причины.
3. Сохраняй строгие TypeScript-контракты на границах компонентов и API. Не скрывай несовместимости через `any` или широкие casts.
4. Размещай SCSS Module рядом с компонентом. Глобальные стили меняй только для reset или действительно глобальной основы приложения.
5. Ограничивай изменение текущей фичей. Не создавай абстракции, re-export-файлы или новые зависимости без фактического потребителя.

## Проверка

Проверь изменённый пользовательский сценарий и запусти минимальные относящиеся к нему проверки. Для обычного изменения кода итоговая проверка проекта — `npm run check`. Сообщи, какие проверки действительно выполнялись.
